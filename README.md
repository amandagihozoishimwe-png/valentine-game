## ✨ Features

* **🐱 Expressive Animated SVG Cat:** Dynamically changes facial expressions (happy eyes, wide eyes, blushing cheeks, and tears) based on user interaction.
* **💌 8-Step Story Flow:** Guides the user through sweet quotes and build-up screens before popping the big question.
* **🏃‍♂️ Runaway "No" Button:** Uses JavaScript event listeners to playfully dodge the cursor while growing the "Yes" button.
* **♿ Accessible Design:** Built with WCAG-compliant color contrast and reduced-motion media queries.
* **⚡ Pure Vanilla Stack:** Built with zero external frameworks or libraries—just clean HTML, CSS, and JavaScript.

## 📂 Project Structure

```text
valentine-game/
├── index.html      # Multi-step card layout & inline SVG cat mascot
├── styles.css      # Keyframe animations, floating hearts & responsive styling
└── script.js       # Step navigation, cat expression states & runaway button logic
```

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the folder**
   ```bash
   cd valentine-game
   ```
3. **Launch the game**
   * Open `index.html` directly in your browser, **or** use **Live Server** in VS Code.

## 🎨 Customization

* **Edit Messages:** Open `index.html` and modify the `<h1>` and `<p>` tags inside `#step1` through `#step8`.
* **Change Fonts:** Swap `Great Vibes` and `Quicksand` in `<head>` via [Google Fonts](https://google.com).
